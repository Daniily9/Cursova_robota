# Company Management System

Курсова робота з об'єктно-орієнтованого програмування на Java.

**Варіант №4 — Система управління працівниками та підрозділами підприємства.**

## Опис проєкту

Company Management System — настільний JavaFX-застосунок для управління підрозділами підприємства та їхніми працівниками.

Програма використовує PostgreSQL для зберігання даних та JDBC для взаємодії з базою даних.

## Використані технології

- Java 17
- JavaFX 21
- PostgreSQL
- JDBC
- Apache Maven
- Jackson (JSON)
- Git та GitHub

## Функціональні можливості

- Перегляд підрозділів підприємства.
- Відображення кількості працівників кожного підрозділу.
- Сортування підрозділів за кількістю працівників.
- Перегляд працівників вибраного підрозділу.
- Додавання, редагування та видалення працівників.
- Додавання, перейменування та видалення підрозділів.
- Масове переведення працівників між підрозділами.
- Розрахунок загального фонду заробітної плати.
- Розрахунок фонду зарплати та відсоткової частки кожного підрозділу.
- Експорт даних у JSON.
- Імпорт даних із JSON.
- Перевірка введених даних та обробка помилок.

## Налаштування бази даних

1. Встановіть PostgreSQL.
2. Створіть базу даних `company_db`.
3. Створіть таблиці за допомогою `database/schema.sql`.
4. Налаштуйте змінні середовища `COMPANY_DB_USER` і `COMPANY_DB_PASSWORD`.

Приклад для PowerShell:

```powershell
$env:COMPANY_DB_USER = "postgres"
$env:COMPANY_DB_PASSWORD = Read-Host "PostgreSQL password"
```

## Запуск програми

Для запуску потрібні Java 17, Maven та PostgreSQL.

```powershell
mvn clean compile
mvn javafx:run
```

## Архітектура

Проєкт використовує принципи об'єктно-орієнтованого програмування, DAO для роботи з базою даних, JavaFX для графічного інтерфейсу та JDBC PreparedStatement для SQL-запитів.
